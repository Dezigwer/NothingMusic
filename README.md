# NothingMusic

**NothingMusic** — лёгкое десктопное приложение для прослушивания музыки через YouTube Music. Отдельное окно вместо лишней вкладки в браузере: плейлисты, подкасты и треки прямо из независимого приложения.

---

## Возможности

- Отдельное окно YouTube Music (WebView2), без лишних вкладок
- Свой заголовок окна или системный (переключатель в настройках), тёмная рамка
- Своё название окна
- Работа в системном трее (закрытие сворачивает приложение в трей)
- Монохромное оформление настроек: белый на чёрном, без цветных акцентов
- Заголовки пиксельным шрифтом Pixelify Sans (открытая лицензия SIL OFL)
- Сохранение размера и настроек между запусками
- Плавные анимации окна и панели настроек (уважают настройки анимаций Windows)

## Настройки звука

Кнопка настроек — в заголовке окна, слева от «свернуть». Ещё три пути: `Ctrl+,`, правый клик по полосе заголовка, пункт в меню трея.
Эффекты применяются на лету через Web Audio API, перезапуск трека не нужен.

| Настройка | Что делает |
| --- | --- |
| **Скорость** | 0.5x–2.0x: slowed / speed up |
| **Сохранять питч** | при замедлении голос не «булькает» (без эффекта бурундука) |
| **Эквалайзер** | низкие / средние / высокие, −12…+12 дБ |
| **Под водой** | ровный lowpass-фильтр: глухой звук без «качаний» частоты |
| **Глубина воды** | сила эффекта «под водой» |
| **Реверберация** | эхо/пространство, 0–100% |

Раздел **ОКНО**: системный заголовок Windows, тёмная рамка, своё название окна.

Все настройки сохраняются в `%LOCALAPPDATA%\NothingMusic\settings.json`.
При первом запуске папка старого имени (`YouTubeMusic`) переносится автоматически — настройки не теряются.

## Установка и запуск

### Готовая сборка (Releases)
1. Перейдите в раздел **Releases**.
2. Скачайте и запустите `NothingMusic.exe`.

### Сборка из исходного кода
```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Для работы требуется **WebView2 Runtime** (в Windows 10/11 обычно уже установлен).

## Оформление

Картинки необязательные — если положить их в папку проекта, они подхватятся при сборке:

| Файл | Что это | Рекомендации |
| --- | --- | --- |
| `logo.png` | логотип слева в заголовке | квадрат, 128×128, прозрачный фон |
| `settings.png` | иконка кнопки настроек | 44×44 (показывается 22×22), белая на прозрачном |
| `ico.ico` | иконка приложения и окна | 256×256 (мультиразмерный `.ico`) |
| `tray.ico` | иконка в области уведомлений | 16/20/24/32 в одном `.ico` |

Если картинок нет, используются символы по умолчанию.

## Шрифт

Заголовки набираются шрифтом **Pixelify Sans** — открытый пиксельный шрифт с кириллицей (лицензия SIL OFL). Текст лицензии — в `PixelifySans-OFL.txt`. Если файл `PixelifySans.ttf` убрать из проекта, интерфейс автоматически вернётся на Segoe UI.

Фирменный **Ndot** не включён в сборку: это собственность Nothing Technology, и распространять его вместе с приложением нельзя.
